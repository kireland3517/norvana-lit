LOCAL ONLY - DO NOT PASTE THESE INTO THE DEPLOYED APPS SCRIPT PROJECT.

These are one-time setup / repair / debug tools. Any top-level function in a
deployed web app can be called by anyone who opens the app, so these (which can
clear orders or reset the dashboard password) must stay out of the live project.

To use one: temporarily paste it into a COPY of the project (like the DEMO copy),
run it there, and never into the live deployment.
